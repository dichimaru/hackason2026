## 6. 決定事項と要確認事項

### 決定済み
- 除外は **直前の1回の当選者のみ**
- 対象(出席者−前回当選者)が当番人数より少ない回は、**前回当選者から補充(連続当番を許容)**。W4・W6 に表示(連続かどうかは計算で出す)
- 当番が決まった後の辞退はない(抽選結果は変更しない)
- **担当の単位は掃除道具**(場所という単位はない)。道具ごとに必要人数と在庫数を持つ。在庫 0 の道具には当番を割り当てない。回の当番人数はその合計(回・エリア単位では持たない)
- **回はエリアごと**(大阪の回・東京の回)。抽選も回ごとに行う。掃除は物理作業のため、社員は所属エリア以外の当番にならない(東京メンバーが大阪を掃除することはない)

- **回は毎週自動作成**(cron 相当)。掃除は毎週金曜 16:00 開始。作成と同時に出欠 DM を送る。W3 は臨時の回の作成用。スケジュールの各時刻は W9 で変更可(初期値は設計書の案)
- 本人確認は **個人別リンク**(社員ごとの token つき URL を DM で送る)。社員の Teams の **UPN**(`employees.teams_upn`)を登録して宛先にする(管理者に依頼。下記)
- 通知は **Workflows の Webhook**(DM 用とチャネル用の2本)。結果は**回ごと**に、当選結果画面(W10・誰でも見られる)の URL だけをチャネルに投稿する
- 社員の出欠は DM のリンクをクリックするだけ(回答用の画面なし)
- **管理者は社員の一部で、管理者ごとに ID/パスワードでログインする**(`admin_accounts`)。セキュリティの方針は 08_security.md

### 要確認
1. **Teams 側の準備(管理者に依頼)**: DM 用 Workflows(宛先をリクエストから受け取る形)の作成と、全社員の UPN の取得。管理者への依頼内容は 4.4 を参照。
