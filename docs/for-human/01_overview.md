# 概要

## 何を作るか
毎週金曜の掃除当番を、**出欠を取って、出席者だけで抽選**して決めるアプリ。連絡は Teams で行う。

## 掃除当日(金曜)の流れ
回は大阪・東京で別々(毎週「大阪の回」「東京の回」ができる)。

| 時刻 | 何が起きるか |
|---|---|
| 09:00 | 回が自動で作られ、そのエリアの全員の Teams の DM に「出席する/欠席する」リンクが届く(クリックで回答完了) |
| 11:00 | まだ答えていない人にリマインドが届く |
| 13:00 | 出欠の受付を締め切る |
| 13:05 | 出席者の中から抽選し、当選結果画面の URL を Teams のチャネルに投稿する(回ごと) |
| 16:00 | 掃除開始 |

時刻は管理者が設定画面(W9)で変えられる。祝日など掃除しない週は、管理者が回を「中止」にする。

## 抽選のルール
- **出席と答えた人だけ**が対象。
- **同じエリアの直前の回で当たった人は外す**(2回連続で当番にならない)。
- 外すと人数が足りない回は、前回当たった人から補って埋める(連続当番を許容)。管理者画面に表示する。
- **当番が決まった後の辞退はない。**

## 当番の人数と掃除道具
- 当番は**掃除道具ごと**に担当する(場所という単位はない)。
- 道具ごとに「必要人数」と「在庫数」を登録する。回の当番人数は、在庫がある道具の必要人数の合計。
- **在庫 0 の道具には当番を割り当てない。**

## 社員はどう回答するか
- 社員は**ログイン不要**。DM に届く**自分専用の「出席する/欠席する」リンクをクリックするだけ**で回答できる。
- 結果は Teams のチャネルの URL から、**誰でも見られる当選結果画面**で確認する。
- 管理者は社員の一部で、**管理者ごとの ID/パスワード**でログインする。

## セキュリティ
- パスワードはハッシュ化して保存し、5回続けて間違えると15分ロックする。初回ログイン時はパスワード変更が必須。
- アプリが持つ社員情報は、氏名・部署・所属エリア・Teams UPN だけ。UPN は管理画面でしか見られない。
- ログイン不要のページ(回答完了・当選結果)は推測できない URL にし、出すのは氏名だけ(部署・UPN は出さない)。
- 管理操作は「誰が・いつ・何をしたか」を記録する。

## 使うもの
- Teams への投稿は Workflows の Webhook(個人宛 DM 用とチャネル用の2本)。
- DM の宛先には、各社員の Teams の UPN(M365 のアカウント名)を登録する。
