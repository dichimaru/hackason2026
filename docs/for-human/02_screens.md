# 画面一覧

見た目は [../wireframes/index.html](../wireframes/index.html) を参照(Figma は古い版)。

## 社員向け
社員が操作する画面はない。Teams の DM の「出席する」「欠席する」リンクをクリックするだけで回答できる(ログイン不要。リンクは本人専用)。クリックすると確認ページ(W2)が開く。

## 誰でも見られる画面
| 画面 | 内容 |
|---|---|
| W10 当選結果 | 回(東京の回 / 大阪の回)ごとに、当番(担当道具・在庫・ポイント)を表示。ログイン不要。Teams のチャネルにはこの画面の URL だけを投稿する |

## 管理者向け
| 画面 | 内容 |
|---|---|
| W0 ログイン・パスワード変更 | 管理者ごとの ID/パスワード。初回はパスワード変更が必須 |
| W1 回一覧 | 回(エリアごと)の一覧。状態と出席数を見る |
| W3 臨時の回の作成 | エリアを選んで臨時の回を作る。作成と同時に出欠 DM を送る |
| W4 回の詳細 | 出欠の状況、抽選の対象、抽選後の当番。回の中止 |
| W6 当番履歴 | 前回の当選者(次回の除外対象)と過去の当番 |
| W7 社員管理 | 社員の登録・編集・休止、エリア、UPN |
| W8 掃除道具管理 | エリアごとの掃除道具(ポイント・必要人数・在庫数) |
| W9 自動作成の設定 | 掃除の曜日と開始時刻、各時刻 |

## Teams に届くもの
1. 出欠のお願い(DM。「出席する」「欠席する」リンク付き)
2. 未回答者へのリマインド(DM)
3. 抽選結果(チャネルに、回ごとに当選結果画面 W10 の URL だけを投稿)
