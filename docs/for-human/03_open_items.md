# 決まったこと・確認したいこと

## 決まったこと
- 回は大阪・東京で別々(大阪の回・東京の回)。抽選も回ごと。
- 除外は同じエリアの直前の1回の当選者だけ。足りなければ前回当選者から補う(連続を許容)。
- 当番が決まった後の辞退はない。
- 担当の単位は掃除道具(場所という単位はない)。道具ごとに必要人数と在庫数を登録する。在庫 0 の道具には当番を割り当てない。
- 回は毎週自動作成。掃除は毎週金曜 16:00 開始。出欠〜抽選はすべて当日の掃除開始前に行う。作成と同時に出欠 DM を送る。
- 出欠は DM のリンクをクリックするだけ(ログイン不要)。宛先は Teams の UPN。
- 結果は回ごとに、誰でも見られる当選結果画面の URL だけをチャネルに投稿する。
- 通知は Workflows の Webhook。
- 管理者は管理者ごとの ID/パスワードでログインする。

## 確認したいこと
1. **Teams 側の準備(Microsoft 365 管理者への依頼)**:
   - 個人宛 DM を送る Workflows の作成(宛先をリクエストから受け取る形)
   - 全社員の UPN 一覧(M365 管理センターから CSV で取得)
